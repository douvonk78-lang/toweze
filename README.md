# toweze

## Bastion Route — Tower Defense

Le jeu se trouve dans le projet indépendant [`tower-defense/`](tower-defense/). Il inclut le code source Phaser 3 / TypeScript / Vite, les tests, la documentation et le projet Android Capacitor.

```bash
cd tower-defense
npm ci
npm run dev
```

Consultez le [guide du jeu et de génération d'APK](tower-defense/README.md) et le [rapport de vérification](tower-defense/RAPPORT.md). Les fichiers compilés et les dépendances installées ne sont pas versionnés ; `npm run build` produit `tower-defense/dist/`.
